# intent_MILEAGE — проверка пробега в решении по заявке

## Замысел

Добавить в расчёт решения по заявке проверку пробега авто: не больше
400 000 км; при превышении решение понижается до `review`. Число и правило —
из формулировки задачи в интервью («пробег авто не больше 400 000 км, иначе
решение review»).

## Зачем

Сегодня решение approve / review / reject зависит только от LTV; пробег на
него не влияет никак (код: `backend/src/Domain/DecisionEngine.php`,
`backend/config/rules.php`). Высокий пробег — фактор риска, который должен
отправлять заявку на ручной разбор вместо автоматического одобрения.

## Constraints

- Порог: не больше 400 000 км включительно; правило срабатывает с
  400 001 (формулировка задачи в интервью; «не больше»).
- Правило понижает только `approve` — до `review`. Исходы `review` и
  `reject` не меняются: при LTV > 85 решение остаётся `reject`, даже если
  пробег выше границы — ответ в интервью, вопрос 1, вариант Б
  («`reject` сохраняется — правило ограничивает только `approve`»).
- Существующее поведение кода (не новое требование): пробег `null` или
  ключ отсутствует → HTTP 422 «Пробег от 0 до 500000 км»
  (код: `backend/src/Domain/ApplicationValidator.php`).
- Согласованное новое требование: пустая строка в поле `mileage` — ошибка
  валидации, HTTP 422. Сегодня код молча превращает её в 0 км
  (код: `backend/src/Domain/ApplicationValidator.php`); изменение — ответ
  в интервью, вопрос 2, вариант Б («пустая строка → 422»).
- Существующее поведение кода (не новое требование): LTV считается как
  раньше; `approved_limit` при review = 0 (код:
  `backend/src/Domain/AssessmentService.php`).
- Форма ответа API не меняется: признак причины review (например,
  «из-за пробега») не добавляется — ответ в интервью, вопрос 3
  («без изменений»).
- Существующее поведение кода: верхняя граница валидации пробега —
  500 000 км (код: `backend/config/rules.php`); проверка решения работает
  в зоне до этой границы, значение не меняется.
- Существующие пороги LTV не меняются: approve < 60.0, review до 85.0
  включительно, reject выше 85.0 (код: `backend/config/rules.php`).

## Open questions

   интервью не было).
2. Текст ошибки 422 для пустой строки пробега — открыт (ответа в интервью
   не было; сегодня текст ошибки диапазона — «Пробег от 0 до 500000 км»,
   код: `backend/src/Domain/ApplicationValidator.php`).

## Не входит

- Форма ответа API и признак причины review — ответ в интервью, вопрос 3.
- Изменение порога валидации 500 000 км, текста ошибки диапазона пробега
   и текстов других ошибок 422 — не было в ответах интервью; значения —
   код: `backend/config/rules.php`, `backend/src/Domain/ApplicationValidator.php`.
- Пересчёт уже сохранённых заявок — не было в ответах интервью.
- Исправление расхождения докблока и кода `DecisionEngine` при LTV ровно
  60.0 (`<` vs `<=`) — существующее поведение кода, не требование
  интервью; зафиксировано как не входящее (код:
  `backend/src/Domain/DecisionEngine.php`).
